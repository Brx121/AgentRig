# 前端执行规则

下列规则用于纯前端任务，由 `frontend` 配置启用。规则与框架和样式方案无关。项目可以在 `.harness/ARCHITECTURE.md` 中记录实际的排版体系、页面状态设计和路由层级。

| 领域 | AI 常用做法 | 工程执行规则 |
| --- | --- | --- |
| 页面说明 | 把限制、条件、免责或辅助解释写成视觉上很小、明显弱化的文字，让页面看起来简洁。 | 页面不得依赖小字解释。用户理解或使用页面所必需的信息，必须用正常可读字号和清晰层级呈现，或放入明确的空态、加载态、错误态、确认态；无助于用户完成任务的解释直接删除。 |
| 详情页导航 | 在每个详情页面放置独立的「返回上一级」按钮，用它替代层级导航。 | 不允许在每个详情页面随意使用独立的「返回上一级」按钮替代面包屑。面包屑必须展示当前页面完整的层级路径；上级节点必须支持点击跳转；当前页面节点不允许点击；首页或根模块作为导航起点；导航层级必须与实际路由结构保持一致。 |

## 决策模板

处理前端任务时，AI Agent 必须先回答：

1. 假设与不确定点：哪些信息缺失，采用什么假设？
2. 页面文案与可读性：哪些条件或限制是用户必须知道的？它们应放在正常正文、明确页面状态，还是直接删除？为什么不能仅靠小字解释？
3. 导航层级：实际路由结构是什么？首页或根模块、各级上级节点和当前页面分别是什么？上级节点跳转到哪里？为什么当前页面节点不可点击？
